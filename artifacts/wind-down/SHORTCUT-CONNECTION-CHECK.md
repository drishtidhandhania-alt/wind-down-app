# Shortcut connection check

The Setup action sends the same token-only `POST /api/wind-down/check` request as the iPhone Shortcut. Its automated client tests and existing server endpoint test verify the request and decision behavior in the website/server environment.

Installing and running the Instagram Personal Automation, and confirming that it opens the pause page on an iPhone, still require real-iPhone verification. A desktop browser check does not prove Shortcuts automation behavior or Instagram handoff behavior.
